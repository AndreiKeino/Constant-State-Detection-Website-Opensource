There is the author's article The effective algorithm for constant state detection in time series with the basic description of the algorithm for Constant State Detection. You can read and/or download the article using the provided link.

The article introduces a simple and effective algorithm for constant state detection in the time series. The algorithm, based on the sliding window of variable length, finds all the sections of the time series which have length greater or equal than some given minimal length and have difference between maximal and minimal value in the section less or equal than some given value. It is shown that the computational complexity of the aforementioned algorithm is $O(N \log(N))$, where $N$ is the length of time series.

Actually this algorithm works as two-way one, because the sliding window start and finish indexes are moving quite independently one from another taking into account the maximal window height and the minimal window width restriction.

Algorithm implementation presented on the website can be divided in two main categories:

Algorithm with absolute window height. In this case the maximal window height restriction used as it is described in the referenced article.

Algorithm with relative window height. In this case software will calculate maximal ($max$) and minimal ($min$) values of the timeseries, then it will search windows with the allowed maximal window height value equal to
$(max - min) h_r$ where $h_r$ is the relative window height that you will provide in the input form.
